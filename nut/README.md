# Network UPS Tools

Runs NUT to monitor and manage UPS systems.

## Environment Variables

| Name           | Default       | Description |
| -------------- | ------------- | ----------- |
| `NUT_USER`     | `upsmon`      | Username for accessing NUT |
| `NUT_PASS`     | `password`    | Password for accessing NUT |
| `NUT_UPS_ID`   | `ups`         | ID for the UPS device |
| `NUT_PORT`     | `auto`        | Port that UPS is connected to |
| `NUT_DRIVER`   | `usbhid-ups`  | NUT driver |
| `NUT_UPS_DESC` | "Generic UPS" | Description used for UPS |
